# 亚信科技合同前置审批系统客户介绍页设计

日期：2026-07-30  
状态：已选方案 A，待书面确认

## 1. 目标

制作一页连续滚动的 HTML 客户汇报页面，用于会议投屏、客户讲解和链接转发。页面介绍现有合同前置审批系统的业务流程、核心能力和管理价值，不承担正式系统操作。

## 2. 品牌素材

- 从客户提供的大厅照片中仅提取中央彩色环形 Logo；
- Logo 输出为透明背景图片；
- 页面不得使用大厅照片或黑色背景墙；
- Logo 不重新绘制、不改变比例、不添加发光或渐变效果；
- 亚信科技名称使用文字排版，与 Logo 组合展示。

## 3. 页面叙事

页面按以下顺序连续滚动：

1. 首屏：Logo、亚信科技、系统名称与一句核心价值；
2. 业务挑战：信息零散、风险识别滞后、执行跟踪断层；
3. 业务闭环：销售语音访谈 → AI 信息提取 → 规则预审 → 后台复核 → 项目跟踪 → 数据分析；
4. 五大能力：语音采集、智能提取、风险规则、项目跟踪、组织数据分析；
5. 双端协作：销售移动端与管理端职责分工；
6. 管理价值：减少重复录入、统一审批口径、风险可解释、过程可追溯、管理可量化；
7. 结尾：汇报收束文案与系统入口按钮。

## 4. 视觉方向

- 风格：可信、克制、具有客户汇报质感；
- 主色：深灰、纸白、制度蓝；
- 品牌点缀：从 Logo 提取的橙色与绿色，使用面积保持克制；
- 字体：系统中文无衬线字体；
- 版式：宽屏优先，同时适配手机和常见笔记本宽度；
- 信息组织：使用大标题、流程轴、非等尺寸能力区和产品界面片段，避免同尺寸卡片堆叠；
- 禁止：大厅背景、玻璃拟态、装饰性渐变文字、虚构业务数据和夸大 AI 能力。

## 5. 动效

- 首屏内容轻量淡入；
- 流程节点在进入视口时依次显现；
- 能力区使用 150 至 250 毫秒状态过渡；
- 尊重 `prefers-reduced-motion`；
- 不使用自动轮播、弹跳或干扰讲解的持续动画。

## 6. 实现形式

- 独立静态页面：`public/introduction.html`；
- 页面样式与脚本内置，便于单文件预览和后续传送；
- Logo 作为独立透明 PNG 放在 `public/assets/introduction/`；
- 页面内系统入口链接到 `/admin`；
- 不修改现有销售端、管理端和 API 功能。

## 7. 验收

- 桌面端能够连续滚动完成完整讲解；
- Logo 透明且无大厅画面残留；
- 页面没有横向溢出；
- 流程、功能和业务价值与现有系统一致；
- `/introduction.html`、`/admin` 均可访问；
- 在启用减少动态效果时，内容仍完整可见。
