# 销售端五轮批量访谈设计

## 目标

将销售端逐字段追问改为最多五批问题的访谈。每批问题简短、编号清晰，销售可通过文字或语音一次回答多个问题；提前收集完整时立即结束，不强制凑满五轮。

## 范围

本次只调整销售端访谈编排及提示文案，不改变：

- 2025-11 固定审批模板及字段定义；
- DeepSeek OpenAI 兼容接口和现有 Agent 框架；
- SiliconFlow 语音识别；
- 确定性风险规则；
- 管理后台、Excel 导出和人工提交外部审批流程。

## 轮次定义

- 一“轮”是助手输出一批问题，随后销售提交一次批量回答。
- 新项目的欢迎消息同时输出第 1 批问题。
- 助手最多输出 5 批问题。
- 销售回答后若信息完整，助手直接提示可以送审，不继续提问。
- 第 5 批必须包含当时全部适用的剩余必填项和风险证据；第 5 批回答后不再生成第 6 批问题。
- 恢复历史项目时，从已持久化的销售回答次数和最新字段状态继续计算，不重置轮次。

## 访谈编排

采用确定性批次规划器控制问题范围，Agent 负责从自然语言中提取多个字段、解释风险并生成简洁文本。不能只依赖模型提示词限制轮次。

### 第 1 批：基础信息

收集合同名称、合同金额、GM1、签约客户及评级、回款健康度、最终用户、销售 BU、区域和销售经理。

### 第 2 批：关键风险开关

收集采购、签约链条、上游签署、资金方、背靠背付款、优质白名单、预付款、渠道费用及垫资判断。采购和垫资条件必须在本批确定，以便后续批次展开条件问题。

### 第 3 批：项目说明

收集商机来源、项目背景、签约进展、资金落实、商务条款，以及金额、利润和收入确认方法。

### 第 4 批：条件信息与管控

若涉及采购，批量收集供应商、采购金额与比例、供应商评级和资本、提前采购、第三方核心交付、二次分包、采购条款及垫资详情。同时收集战略契合、产品能力、项目延续性和三类风险管控措施。

同一主题可使用一个复合问题覆盖多个字段，例如“供应商全称、主体类型、评级和实缴资本分别是什么？”；问题与字段保持显式映射，便于测试和 Agent 提取。

### 第 5 批：全部剩余项

重新读取持久化项目，合并：

- 所有适用但未回答的必填字段；
- 风险引擎返回的全部缺失证据字段；
- 适用且尚未回答的承诺字段。

第 5 批不设置普通数量上限，确保全部剩余问题一次出现。相同字段去重，条件不适用的字段不出现。

## 输出格式

每批使用以下格式：

```text
第 2/5 轮，请按编号一起回答：
1. 是否涉及采购？是否存在垫资？
2. 我司处于直签、一级分包还是更下级？上游是否已签？
3. 资金方是否明确？付款是否背靠背？
```

要求：

- 普通批次控制在 6～10 个编号问题；
- 使用短句，不重复字段说明和模板指导语；
- 允许销售按编号、连续口述或自然段回答；
- Agent 每轮先提取当前回答中的所有高置信度字段，再获取下一批问题；
- 不编造缺失信息，不改变风险引擎结论。

## 组件边界

### 批次规划器

在访谈领域模块中新增批次规划能力，输入最新项目和目标轮次，输出：

- 当前轮次；
- 问题列表；
- 每个问题对应的一个或多个字段键；
- 是否为最终批次；
- 是否已可送审。

规划器是纯函数，不调用模型、不写存储，便于覆盖无采购、采购、垫资和历史恢复场景。

### Agent

Agent 保留现有字段提取、风险评估和送审检查工具，将单题工具替换为“获取下一批问题”。提示词明确：

- 一次提取多个字段；
- 严格使用规划器返回的问题；
- 不拆成逐题追问；
- 第 5 批之后只输出完成状态或缺项摘要，不提出新问题。

### 启动接口

新项目创建后，根据空项目生成第 1 批问题并写入消息历史，替换当前只询问合同名称的欢迎语。

## 异常与边界处理

- 销售漏答：下一批优先携带仍缺失的关键字段；第 5 批包含全部剩余项。
- 销售提前提供后续信息：已提取字段自动从后续批次移除。
- 条件变化：以持久化最新值判断采购和垫资字段是否适用。
- 五轮后仍不完整：不生成第 6 批；页面保留送审阻断，助手只说明尚未满足送审条件，并展示缺项摘要。
- 模型未调用批次工具：提示词和工具说明要求其在字段提取后必须调用；自动化测试验证批次规划器的硬上限。

## 验收标准

1. 新项目首条助手消息包含第 1/5 轮和一组编号问题。
2. 普通批次包含 6～10 个简短问题。
3. 无采购项目、采购项目和采购加垫资项目均在最多五批内输出所有适用问题。
4. 第 5 批包含全部剩余必填字段、风险证据和适用承诺字段。
5. 第 5 批之后不再返回新的问题批次。
6. 提前完成时少于五轮结束。
7. 原有风险、送审、语音、Excel 和后台测试继续通过。
